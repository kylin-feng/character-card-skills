# MiniMax 出图（文生图 / 人物主体参考图生图）

走 MiniMax 开放平台官方接口，零第三方依赖，脚本自动落盘。

**这个技能存在的理由**：内置 `ImageGen` 并非每个会话都存在，`mcp__media__*` 也可能未接入。
当这些通道都不可用时，本技能提供一条**确定可用**的生图路径。

## 能力

| 能力 | 说明 |
|---|---|
| 文生图 | 纯文字描述出图 |
| **图生图（人物主体参考）** | 传一张人物参考图，模型保留该人物特征，生成新场景/新动作——**跨镜角色一致性的关键手段** |
| 批量 | 单次最多 9 张 |
| 复现 | 固定 `seed` + 相同参数可复现结果 |
| 画风 | `image-01` 写实细腻；`image-01-live` 手绘/卡通增强 |

## 前置：凭据

API Key 存放于 `~/.workbuddy/secrets/minimax.env`（**本机用户目录，不在任何 git 仓库内**）。
脚本读取优先级：`--api-key` 参数 > 环境变量 `MINIMAX_API_KEY` > 该文件。

没配 key 时脚本会明确报错并给出配置位置，**不要试图绕过或伪造**。

## 调用方式

```bash
PY="C:/Users/FengQ/.workbuddy/binaries/python/versions/3.13.12/python.exe"
SKILL="C:/Users/FengQ/.workbuddy/skills/minimax-media/scripts/minimax_image.py"

# 文生图（竖构图）
"$PY" "$SKILL" --prompt "雪夜路灯下的银发少女，猫耳，头顶金色光环" \
  --aspect 9:16 --out "./out" --name "linming-snow-night"

# 图生图 —— 保持角色长相，换场景
"$PY" "$SKILL" --prompt "同一位少女坐在教室窗边翻书，午后阳光" \
  --ref "./assets/refs/ref-01-rooftop-sunset.jpg" --aspect 4:3 --out "./out"
```

`--json` 输出结构化结果（含 task_id、落盘路径），便于后续处理。
`--dry-run` 只打印将要发送的请求，**不产生费用**——拿不准参数时先用它。

## 人物一致性怎么用

这是本技能最有价值的部分，也是麟鸣这类 IP 的核心诉求。

```json
"subject_reference": [
  { "type": "character", "image_file": "<公网 URL 或 data:image/jpeg;base64,...>" }
]
```

**硬性限制（照抄官方，不要想当然）**：

- 数组长度**只支持 1**，一次只能参考一张图
- 参考图必须是**单人人脸正面照**，模型才能正确提取人像信息
- 格式仅 `jpg` / `jpeg` / `png`，体积 **< 10 MB**
- 本地文件由脚本自动转 base64 data URL，无需手工编码

**实践建议**：从同一角色的参考图里挑**最正、脸最清楚**的那张作主体参考，其余图用作场景/服装参考写进 prompt。

## 关键参数

| 参数 | 取值 | 说明 |
|---|---|---|
| `--model` | `image-01`（默认）/ `image-01-live` | live 版画风增强 |
| `--aspect` | `1:1` `16:9` `4:3` `3:2` `2:3` `3:4` `9:16` `21:9` | 21:9 仅 image-01 |
| `--n` | 1–9 | 默认 1 |
| `--seed` | 整数 | 固定以复现 |
| `--optimize` | 开关 | 开启后模型自动改写 prompt |
| `--watermark` | 开关 | 默认**不加**水印 |

prompt 上限 **1500 字符**，脚本会提前校验。

## 结果与常见错误

响应内 `base_resp.status_code` 非 0 即为失败，脚本会翻译成人话：

| code | 含义 | 该怎么办 |
|---|---|---|
| 0 | 成功 | — |
| 1002 | 限流 | 降并发/稍后重试 |
| 1004 | 鉴权失败 | 检查 key |
| 1008 | 余额不足 | 去账户充值 |
| 1026 | 描述敏感 | 改写 prompt |
| 2013 | 参数异常 | 查参数取值 |
| 2049 | 无效 key | key 失效，重新获取 |

`metadata.failed_count > 0` 表示有图被内容安全策略拦截，**不算请求失败**，脚本会提示。

## 诚实边界

- **图是模型生成的，不是精确作画**。同一 seed 也只能"相近"，不能保证像素级一致。
  跨镜一致性靠参考图显著改善，但**做不到 100%**。
- **本技能不解决"看图"**——如果当前模型不支持读图，就别去描述参考图的配色/材质，
  那些信息必须来自文本资料或用户口述。
- **生图会产生费用**。批量出图或反复重跑前，先跟用户确认。
- 接口返回图片 URL 的有效期只有 24 小时，所以脚本一律用 base64 直接落盘归档。
