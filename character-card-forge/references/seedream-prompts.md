# Seedream 生图指令模板

> 配套 `character-card-forge`。给豆包 Seedream 4.0 用。
> ⚠️ **豆包吃自然语言长句，不要用 `(keyword:1.3)` 权重语法**——那是 Stable Diffusion 方言。

---

## 核心原则

**一致性靠参考图，不靠提示词。** 文生图跨镜必然漂移，参考图路线是唯一可靠解。

流程固定为：**基准图 → 确认 → 之后全部以基准图为参考**。
不要每次都回头用原始素材，那样会累积漂移。

---

## 指令 1 · 基准图（最重要，先做这个）

### 有参考图时

```
以我上传的图为参考，这是同一个角色。请严格保持她的<发型发色>、<兽耳>、
<标志配饰>、<瞳色>、<服装款式与配色>完全一致。

生成一张半身正面像：角色面向镜头，<表情>，纯白背景，无任何文字水印。
<画风>，柔和光影，高质量。
```

### 无参考图时（纯文生图）

```
生成一张动漫角色半身正面像。

角色：<性别><年龄感>，<发色><发型><发长>，<刘海形状>；<兽耳/头饰>；
<瞳色><眼型>；穿<服装款式>，<配饰细节>；<表情>，<脸颊特征>。

画面：纯白背景，面向镜头，无文字水印。<画风>，柔和光影，高质量。
```

> ⚠️ 只在**真实读过图**或**用户明确告知**时才写具体颜色。
> 没读过图就用参考图路线，让颜色由图自己说话。

## 指令 2 · 三视图

```
以参考图角色为准，保持所有外貌特征完全一致。

生成角色设定三视图：同一张图里从左到右依次为正面全身、侧面全身、背面全身，
站立姿势，纯白背景，角色比例统一。

注意：背面视角也要能看到<从背后可见的特征，如光环/发饰垂带/披风>。
```

---

## 指令 3 · 表情差分（九宫格）

```
以参考图角色为准，保持外貌完全一致。

生成九宫格表情差分，均为面部特写、纯白背景，依次为：
温柔微笑 / 惊讶睁大眼 / 害羞脸红别开视线 / 委屈眼含泪 / 认真坚定 /
得意闭眼笑 / 困倦半睁眼 / <角色专属弱点反应> / 落寞垂眼淡笑
```

**强化技巧**：给有情绪道具的角色，逐格补状态。例如：

- 害羞格 → 「头顶光环泛出淡粉色」
- 认真格 → 「光环放大、边缘浮现十字光芒」
- 说谎/心虚格 → 「光环暗淡闪烁」

## 指令 4 · 场景图

```
以参考图角色为准，保持外貌完全一致。

场景：<地点>，<天气/时段>，<光源>，<背景元素>，<色调对比>。
角色<姿势>，<构图：半身/全身>，<表情>，<视线方向>。
电影感光影。
```

### 常用场景词库

| 场景 | 关键描述 |
|---|---|
| 黄昏天台 | 夕阳天空，戏剧性云层，城市建筑背景，暖色逆光 |
| 教室日常 | 午后阳光透窗，黑板背景，课桌，暖色室内光 |
| 雪夜街道 | 飘雪，暖色路灯，欧式街景，背景光斑虚化，冷蓝与暖橙对比 |
| 深夜厨房 | 昏暗暖光，蒸汽，围裙，只有一盏灯亮着 |
| 废墟遗迹 | 断柱，杂草丛生，光柱中的尘埃 |
| 雨天车站 | 大雨，伞，地面积水倒影，雷雨 |
| 樱花街道 | 花瓣飘落，春天，柔和粉色光 |

## 指令 5 · 镜头语言

在场景指令后追加：

| 镜别 | 追加描述 | 用途 |
|---|---|---|
| 大远景 | 广角，全身，突出环境 | 建立场景、开场 |
| 中景 | 半身构图 | 日常对话主力 |
| 特写 | 面部特写，突出眼睛细节 | 情绪爆点 |
| 仰角 | 低角度仰拍，有压迫感/神圣感 | 气势、守护 |
| 俯角 | 高角度俯拍 | 脆弱、孤独 |
| 过肩 | 过肩视角，从背后拍 | 双人对话 |
| 眼睛特写 | 极近特写，眼中有<反光物>倒影 | 高潮、泪点 |

## 一致性避坑清单

跨镜最容易丢的东西，**每镜都要重复写**：

1. **特殊符号最易丢**（光环、刺青、瞳纹）→ 每条指令都要提
2. **配饰颜色易漂**（领带、蝴蝶结、宝石）→ 明确写颜色，或依赖参考图
3. **发色易被"主流化"**（银白→金发、紫发→黑发）→ 明确强调
4. **兽耳易被头饰吃掉** → 单独一句描述位置
5. **瞳色易变蓝** → 明确写
6. **背面镜头** → 提醒哪些特征从背后仍可见
7. **一次只改一个变量** → 换场景别同时换表情，崩了不知道哪出问题

## 生图工具调用备忘

**先查可用工具，按优先级降级：**

| 优先级 | 工具 | 参数 |
|---|---|---|
| 1 | `mcp__media__generate_image`（media MCP） | `prompt` 必填，中文自然语言；`size`: `1K` 默认 / `2K` / `4K` |
| 2 | 内置 `ImageGen`（经 `ToolSearch` 加载） | `prompt` 必填 |
| 3 | 都没有 | ⚠️ **不要假装能生图**，输出可粘贴的指令文本让用户自己去豆包生成 |

- 模型：`doubao-seedream-4-0`
- 返回图片 URL 和本地路径，**交付本地路径给用户**
- ⚠️ 无论哪条路线，都**不要手写 curl 或脚本绕道调 API**

## 视频化（可选）

工具：`mcp__media__generate_video`（media MCP）或内置 `VideoGen`，模型 `MiniMax-H3`

| 参数 | 建议 |
|---|---|
| `resolution` | `768P` 起步（最便宜），确认效果再上 `2K` |
| `duration` | `5` / `10` / `15` 秒 |
| `ratio` | 竖屏漫剧用 `9:16` |
| `first_frame_url` | 图生视频，放基准图或分镜图 |

长任务用 `wait=false` 拿 `task_id`，再用 `query_video_task` 轮询。
